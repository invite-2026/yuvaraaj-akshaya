Drop your wedding song into this folder and name the file exactly:

    song.mp3

That's it — no code changes needed. The site is already wired to look for
audio/song.mp3 and will automatically:
  - Play it (fading in) the moment a guest clicks "Open Invitation"
  - Show a small round music toggle in the bottom-right corner once the
    file is detected, so guests can mute/unmute
  - Stay silent and hide the toggle if no file is present, so nothing
    breaks if you skip music

Keep the filename as song.mp3 (mp3 format works everywhere). If you
want to swap songs later, just replace the file — same name, same spot.
